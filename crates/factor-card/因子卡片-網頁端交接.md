# 因子卡片：顯示規則變更交接（給網頁端 stallion 卡片同步用）

這份文件記錄 Hachimi 內建「因子卡片 PNG」相對於**網站原本 stallion 展開卡**做了哪些顯示規則的改動。
網頁端（`繁中服賽馬娘種馬資料庫`）要跟進的話，照這份逐條改即可。

實作位置（Rust，可直接對照）：

| 檔案 | 內容 |
|---|---|
| `crates/factor-card/src/data.rs` | 因子分類、排序、統計計算（＝網頁 `stallion-data.jsx` 的對應物） |
| `crates/factor-card/src/render.rs` | 版面與配色（＝`stallion.css` + `stallion.jsx` 的對應物） |
| `crates/factor-card/assets/*.json` | 直接複製自網站 `static/{factor,card,race}_map.json` |

沒有改動的部分：`apply_extends`、`classify_factor`（藍<1000／紅<10000／綠>=1e7／其餘白）、
隱藏因子判定（type 5/7/9 + 稱號覺醒 50016–50021 例外顯示）、三方共鳴的計算方式。

---

## 1. 遺傳子（○○的基因）改用紅色

factor group `50001`–`50010`（場地／距離／腳質的「○○的基因」）性質等同適性，
所以 **badge 改成跟紅因子同一個樣式**，三方共鳴的 chip 也一樣。

```
50001 草地的基因   50002 沙地的基因
50003 短距離的基因 50004 一哩的基因   50005 中距離的基因 50006 長距離的基因
50007 領頭的基因   50008 前列的基因   50009 居中的基因   50010 後追的基因
```

注意這些 group 的 `factor_type` 是 8/10/11，不在隱藏類型（5/7/9）裡，本來就會顯示，
只是原本被當成白因子上米色。

## 2. 覺醒因子改用 T1 青綠

group `50016`–`50021`（順時針／逆時針／春／夏／秋／冬 的覺醒）改成 `fb-t1` 青綠色，
跟「春賽馬娘○」那類同色。三方共鳴 chip 同樣處理。

## 3. 因子排序

原本：藍 → 紅 → 綠 → 白
改成：**藍 → 紅 → 遺傳子 → 綠 → 覺醒 → 白**

遺傳子緊接在適性後面（顏色相同、視覺集中），覺醒排在一般白因之前。
組內維持原本順序（穩定排序）。

對應 `data.rs::sort_rank()`。

## 4.「本體白因」→「有效白因」

計算方式：**實際會顯示出來的白因數量，再扣掉遺傳子**。
（賽事因子、大部分稱號因子本來就被隱藏規則濾掉；覺醒類仍然計入。）

```
有效白因 = count(白因分類 && !is_hidden && !is_gene_group)
```

驗證用例（trained_chara_id 12423，[重瓣花朵]西野花）：本體/父/母 = **10 / 13 / 8**

## 5. 上排統計格改成「三方分布」

原本 8 格單一數字（藍總星／紅總星／綠總星／本體白因／稀有技能／G1勝場／追蹤／被借用）
改成 **3 格，每格縱向列出 本體 / 父 / 母**：

| 格子 | 內容 | 範例（西野花） |
|---|---|---|
| 藍/紅/綠/有效白分布 | 四段一行，各自上色，以灰色 `/` 分隔 | `1耐 / 2哩 / 2 / 10` |
| 遺傳子分布 | 同一套縮寫，紅字 | `1沙2哩2中` |
| G1勝場 | 單一數字（之後要擴充） | `23` |

**移除**：稀有技能、被借用。
**移到標題列**：追蹤數（見下一節）。

### 縮寫對照

```
藍（屬性）  1 速度=速  2 持久力=耐  3 力量=力  4 意志力=根  5 智力=智
紅（適性） 11 草地=草 12 沙地=沙 21 領頭=領 22 前列=前 23 居中=居 24 後追=後
           31 短距離=短 32 一哩=哩 33 中距離=中 34 長距離=長
遺傳子     50001–50010，○○ 的名稱與紅因相同，共用同一套縮寫
```

同一方有多顆同色因子就串起來（例：速度★2＋持久力★1 → `2速1耐`）；
沒有該類因子顯示 `—`；沒有父／母那一行整行 `—`。

綠因（固有）名稱太長，只放星數合計。

## 6. 標題列

```
[重瓣花朵]西野花    UID 479790670    追蹤 220
```

- UID＝`viewer_id`（原本這裡放的是 `trained_chara_id`，已移除）
- 追蹤＝`follower_num`。**這個欄位不在 trained_chara 裡**，遊戲端是從好友頁 API
  （`data.follower_num`）撿的；網頁端本來就有 UID 查詢，直接沿用即可
- 兩者都用 `--ink-soft` 粗體，不要用 `--ink-mute`（太淡）

## 7. 配色微調

- **所有 badge 都加外框**（原本只有 t0/t1/green 有）
- **藍因子加深**：底 `rgba(74,143,200,.12)` → `.22`，字 `#2c6a9e` → `#1b4f7d`，加藍框
  （T1 白因變多之後，淺藍跟青綠太像）
- 紅因子：底 `.12` → `.18`，字 `#a04848` → `#933d3d`，加紅框
- 白因子：底 `.15` → `.18`，字 `#7a6840` → `#705e38`，加框 `rgba(184,168,120,.5)`

暗色主題沿用網站既有的 `[data-theme="night"]` 那套值，沒有另外發明。

## 只有圖片版才有的東西（網頁端不需要）

- 卡片預設**暗色**主題，選單可切亮色（設定存在 `config.json: factor_card_light_theme`）
- 正中央 ASKR logo 浮水印：裁掉外框 4% → 從邊緣洪水填充去白底（角色內部的白要保留）
  → 文字帶（上方 24%）額外去白（筆畫圍起來的白不與邊緣連通）→ 暗色主題整體提亮 55%
  → 以 34% 寬、10% 不透明度置中疊上
- 輸出：CSS px 版面 × scale（目前 2.0），卡片寬 1040 → PNG 2080px 寬
